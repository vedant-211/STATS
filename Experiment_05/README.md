# Experiment 05: Resampling Techniques

## Aim
To use non-parametric resampling methods to estimate distributions and test hypotheses.

## Bootstrap Resampling Summary
- **Metric**: Mean Glucose
- **Bootstrap 95% CI**: (119.65, 123.77)

## Permutation Test Summary
- **Metric**: Difference in Mean BMI between Outcome groups
- **Observed Difference**: 4.4980
- **Empirical p-value**: 0.0000

## Student Questions & Answers
1. **What is bootstrapping?** A resampling method with replacement used to estimate the sampling distribution of a statistic.
2. **Is the permutation test result consistent?** Yes, like the t-test, the permutation test yields a significant result (p=0.0000).
3. **Why use resampling?** It does not rely on strict normality assumptions required by traditional parametric tests.
